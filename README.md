# Flores amarillas

Experiencia web estática creada con HTML, CSS, JavaScript, SVG y GSAP.

## Abrir el proyecto

Abre `index.html` directamente en el navegador. GSAP y las tipografías se cargan desde CDN, por lo que conviene tener conexión a internet.

Para personalizar el destinatario, añade el parámetro `para` a la URL:

```text
index.html?para=Mariana
```

En un dominio funcionaría así:

```text
https://tudominio.com/?para=Mariana
```

## Archivos principales

- `index.html`: estructura y ramo SVG.
- `css/styles.css`: diseño y adaptación responsive.
- `js/app.js`: animaciones, flores interactivas y personalización.

Las configuraciones principales están al inicio de `js/app.js` dentro de `CONFIG`.
